|----------|-------------|
| User browser → landing inline JS | Single-page execution; only event-listener registrations + display-mode reads; no user input flows back to a server. |
| `beforeinstallprompt` event handler | Browser dispatches the event; the handler stashes it and reveals the button only after a user-gestured click does `prompt()` is called. |
| `<details>` panel content | Static HTML; no untrusted input ever populated into the disclosure body. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Spoofing | `beforeinstallprompt` event handler hijacked / fired programmatically | accept | The browser fires the event from a trusted (chrome-internal) source after engagement heuristics; web pages cannot synthesize it (the event constructor `BeforeInstallPromptEvent` is browser-only). Risk = null in standards-compliant browsers. |

| T-11-02-03 | Repudiation | Inline script writes nothing to logs/analytics; "did the user click install?" is unrecoverable | accept | No analytics in scope per PROJECT.md "Out of Scope". The `appinstalled` event is purely client-side state. Risk = matches design intent. |
