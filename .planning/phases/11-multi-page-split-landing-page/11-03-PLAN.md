<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `app/index.html` → React bundle | The `<script type="module" src="/src/main.tsx">` line bootstraps the entire app; if the path resolution breaks, the app shell becomes a blank page. |
| Apple PWA meta → iOS install | The 4 apple-* meta tags + `<link rel="apple-touch-icon">` are read by iOS Safari when the user taps Share → Add to Home Screen. Wrong icon path → broken home-screen icon. |
| JSON-LD url → search engine canonicalization | The `url` field tells crawlers which URL is canonical for the WebApplication entity. Wrong value → crawler indexes the wrong URL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Spoofing | Wrong canonical URL pointing crawlers at the landing instead of the app shell | mitigate | canonical href is `https://soundly.local/Soundly/app/` — the deploy-time swap (Plan 11-05 runbook update) keeps the `/app/` suffix when replacing the host. Plan 11-05 test asserts the value. |
| T-11-03-02 | Tampering | `<script src="/src/main.tsx">` path resolution breaking the app shell when launched from `/app/` | mitigate | Vite resolves `/src/main.tsx` against the project root regardless of HTML file location (RESEARCH Finding 1). Verified manually via `npm run dev` → `/Soundly/app/` renders. No code change to `src/main.tsx` required. |
| T-11-03-03 | Information Disclosure | App-shell SEO meta accidentally exposing internal data | accept | The meta block uses the same Phase 10 description / OG copy (publicly approved). No internal data in scope. |
| T-11-03-04 | Repudiation | Apple PWA meta tags lost during the move (root → app/) → home-screen install on iOS silently broken | mitigate | All 4 apple-* tags moved verbatim per RESEARCH Finding 9 + PATTERNS Pattern Assignment 2. Plan 11-05 adds 4 dedicated test assertions (`apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style`, `apple-mobile-web-app-title`, `apple-touch-icon`) on `app/index.html`. |
| T-11-03-05 | Denial of Service | `<link rel="manifest">` auto-injection failure → PWA install no longer offered | mitigate | RESEARCH Q4 OPEN — Plan 11-05's `scripts/verify-phase-10-build.mjs` update asserts `<link rel="manifest" ...>` is present in `dist/app/index.html`. If absent, Phase 10 D-25 fallback applies: manually add `<link rel="manifest" href="/Soundly/manifest.webmanifest">` to `app/index.html` source. |
| T-11-03-06 | Elevation of Privilege | n/a | accept | No privilege boundaries crossed — pure static HTML + standard React bundle entry. |
