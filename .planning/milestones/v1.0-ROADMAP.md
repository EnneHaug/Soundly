## Milestone Goal

Ship a working gentle-alarm PWA: synthesized audio, three-phase escalation (gentle sound → vibration → volume ramp), two presets (Quick Nap and Focus), Dashboard + Countdown UI, installable PWA shell with offline support, and platform integration (Wake Lock, notifications, vibration with iOS fallback).

## Accomplishments

- **Audio engine:** Web Audio API singing bowl synthesis, click-free attack envelopes, Phase 3 swell with linearRampToValueAtTime, AudioContext singleton with autoplay-policy handling, keepalive oscillator for background reliability
- **Alarm state machine:** Three-phase escalation (gentle → vibration → wake) with deterministic transitions, drift-corrected wall-clock timer, AlarmConfig type with two locked presets (Quick Nap 5+5+10s, Focus 21+2+10s)
- **Platform integration:** Wake Lock API with `visibilitychange` re-acquisition (per [MDN Baseline 2025](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)), `ServiceWorkerRegistration.showNotification()` with tag deduplication, Vibration API with iOS tick-pulse audio fallback
- **PWA shell:** vite-plugin-pwa with custom service worker, Workbox precaching, install prompts for Android Chrome (`beforeinstallprompt`) and iOS Safari (manual Add-to-Home-Screen)
- **React UI:** Tailwind v4 warm-earth palette (sage / sand / accent / faded), reusable PresetCard with 80px touch targets, Countdown with byte-identical-stable Tailwind class strings, ProgressRing SVG with three-arc geometry + Phase 3 dot, IosInstallBanner with display-mode detection
- **Test discipline:** TDD across audio synthesis (envelope assertions via Web Audio API mocks), state machine transitions, format utility, notification fallbacks, iOS detection
